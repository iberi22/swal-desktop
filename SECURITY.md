# Security Policy

## Supported Versions

The following versions of the project are currently being supported with security updates.

| Version | Supported |
| ------- | ------------------ |
| Latest release | :white_check_mark: |
| Default branch (`main`) | :white_check_mark: |
| Older releases | :x: |

## Reporting a Vulnerability

Please report vulnerabilities **privately** via GitHub Security Advisories by clicking the "Report a vulnerability" button on this repository's Security tab.

**Do not** open public issues for security reports.

**Do not** mention or speculate about any specific vulnerability in public issues, pull requests, or comments.

## Response Targets

- **Acknowledgement:** Within 5 business days.
- **Status Update:** Within 14 days.
- **Disclosure:** We practice coordinated disclosure.
- **Bug Bounty:** There is currently no bug bounty program.
