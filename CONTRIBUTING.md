# Contributing

Thank you for your interest in contributing to SWAL Desktop!

## Workflow

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes and write conventional commits.
4. Run tests before submitting a Pull Request.

## Commits

We use [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) for our commit messages.
This allows us to automatically generate changelogs and version bumps.

## Testing

Before opening a PR, ensure that all tests pass. This repository contains tests in various languages and frameworks,
such as Rust (via Cargo), Python, and bash scripts. Please refer to our CI configuration to see the exact tests
that will be run on your PR.
